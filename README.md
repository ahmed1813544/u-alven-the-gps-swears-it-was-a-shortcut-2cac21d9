Entry for the [make.fun bounty "The GPS Swears It Was a Shortcut"](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

A stdlib-only Python program (`main.py`) that writes the GPS's one-line excuse,
in its own voice, for sending the driver down the wrong road, to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
Deterministic: the same line, byte for byte, on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
